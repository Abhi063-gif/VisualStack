# VisualStack Studio — Development Roadmap

## Phase 1: Core IDE Foundation (Module 01) — COMPLETED
- Complete desktop shell layout, panel resizing, Monaco integration, Konva canvas, React Flow canvas, Zustand stores, EventBus, Command Engine.

## Phase 2: Visual UI Designer Engine (Module 02)
- Canvas element drag-and-drop, bounding box selection, auto layout, constraints, custom component palette.

## Phase 3: Visual Backend Designer (Module 03)
- Node graph editor, flow execution engine, topological sorting, async node contracts.

## Phase 4: API Bridge (Module 04)
- Direct visual mapping of UI component events (onClick, onSubmit) to backend flow endpoints.

## Phase 5: Code Generation Pipeline (Module 05)
- Multi-compiler pipeline turning `.vstack` JSON into full React + Express codebase.

## Phase 6: Runtime Engine, Deployment & AI (Module 06)
- Live preview server, Vercel/Netlify/Docker deployment adapters, schema-validated AI patch engine.
