# VisualStack Studio v1.0.0 Production Release Notes

We are excited to announce the official **Version 1.0.0 Production Release** of VisualStack Studio!

## 🚀 What's New in v1.0.0

- **Multi-User Real-time Collaboration**: Live cursors, selection highlights, user avatars, and session token isolation (`SessionManager`).
- **Project Sharing & Granular Permissions**: Role-based access control (`Owner`, `Admin`, `Editor`, `Developer`, `Viewer`, `Guest`) and share link generator.
- **Threaded Comment System**: Attach pins to canvas UI shapes, backend logic nodes, and code files with @mentions and reply threads.
- **Version Timeline & Checkpoints**: Named checkpoints, visual snapshot history, and 1-click restore.
- **16+ Fullstack Project Templates**: Initialize E-Commerce, CRM, SaaS Landing Page, Portfolio, Auth, Chat, or Food Delivery apps with 1 click.
- **Visual Plugin Marketplace & SDK**: Extend VisualStack Studio with official and community plugins using `VisualStackPluginSDK`.
- **Enterprise Features**: Global Design System tokens, 7 icon libraries, 8 i18n language packs, and license manager.
