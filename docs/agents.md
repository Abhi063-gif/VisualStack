# Autonomous Agents Architecture

## Execution Flow
1. User provides goal prompt (e.g. "Build a food delivery app").
2. `TaskPlanner` breaks goal into structured subtasks:
   - System Architecture Blueprint
   - UI Scene Graph Generation
   - Backend React Flow Logic Node Generation
   - Database Schema & Auth Setup
   - TypeScript Compilation & Test Verification
   - Git Commit & Cloud Deployment Setup
3. `AutonomousAgent` sequentially executes tasks, calling `ToolCallingEngine` APIs as needed.
